👑 Sobre o projeto

PAINEL GAME — RED & PURPLE

Uma interface gamer independente, feita em HTML, CSS e JavaScript. Funciona no navegador e se adapta a celulares e computadores.

Importante: este painel é uma interface web. Ele organiza atalhos, informações disponíveis no navegador e opções visuais. Não altera configurações internas do Android nem aumenta FPS ou memória do aparelho.
